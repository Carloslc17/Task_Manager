# Task_Manager
Este repositorio contiene una aplicación de gestión de tareas (to-do / task manager) escrita en Python. Comenzó como un proyecto con Flask y se está migrando progresivamente a Django, con el objetivo de comparar arquitecturas, manejo de rutas, ORM y estructura de proyecto entre ambos frameworks.

Estado del proyecto: 🚧 En desarrollo — versión Flask funcional, migración a Django en curso.
